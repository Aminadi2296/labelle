# La Belle Medspa – Web (Next.js + Tailwind)

```bash
npm install
npm run dev   # http://localhost:3000
```

- Contenido (sedes, servicios, métricas): `lib/data.ts`
- Botones de reserva: `BOOKING_URL` en `lib/data.ts` (se conectará a la API de reservas)
- Imagen del hero: `public/hero.png` (se optimiza a WebP con next/image)
